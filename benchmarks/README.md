# Stress benchmark artifacts

Generated by `npm run benchmark:stress`.

## Commands

| Command | Purpose |
|---------|---------|
| `npm run benchmark:stress` | Run tests + standard profile (< 1k focus) |
| `npm run benchmark:stress:full` | Include `castle10000` estimates |
| `npm run benchmark:stress -- --displacement` | Estimate extra height-blit pass per object |
| `npm run benchmark:stress -- --json benchmarks/YYYY-MM-DD.json` | Save dated snapshot |

## Files

- **`stress-latest.json`** — overwritten on each run (machine-readable)
- **Dated copies** — commit or archive manually for trend tracking

## What the numbers mean

| Field | Meaning |
|-------|---------|
| `shaderPassesPerFrame` | `objects × (2 + displacement)` full-screen shader draws |
| `pixelsWrittenPerFrame` | Passes × tileSize² — fill-rate proxy |
| `rtMemoryBytes` | Rough RGBA half-float RT pool size (5 targets/object) |
| `relativeShaderCost` | Ratio vs `plane2d` @ 16 objects |
| `cpuBenchmarks[].medianMs` | CPU-only layout/generation (not GPU) |

**Ground truth:** enable the FPS overlay in the app while stress modes run. Particles at equal object counts should land near cubes/castle tiles with the same RT tier — sprite motion is not the bottleneck.
